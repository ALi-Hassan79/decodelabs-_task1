# 🤖 RuleBot — Rule-Based Chatbot

RuleBot is a simple, interactive chatbot built using HTML, CSS, and JavaScript. It uses basic **if/else statements and keyword matching** to understand user messages and generate predefined responses without using any AI model.

## ✨ Features

* 💬 Interactive chat interface
* 🧠 Rule-based responses using JavaScript if/else logic
* 🌍 Multilingual support: English, Urdu, Spanish, French, and Arabic
* 👋 Greeting and goodbye detection
* 😂 Jokes, fun facts, and predefined answers
* 🕒 Real-time date and time responses
* 📋 Chat history to view previous questions
* ⌨️ Send messages using Enter or the Send button
* 📱 Responsive interface with a collapsible sidebar
* ✨ Typing animation for chatbot responses

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation

## ⚙️ How It Works

RuleBot uses keyword matching and conditional statements to classify user messages into predefined categories, such as greetings, jokes, help, and questions about the time or date.

Based on the matched category, it selects a predefined response in the selected language. If no rule matches, it provides a fallback response.
